# 全屏 SSH 与移动输入

本轮键盘与发送体验改进基于已发布 `9eb94af2e8697c94cae4d5e0ae8afa0590651771`；不改变凭据、主机信任、SQLite schema 或远端授权。SSH 继续通过 dartssh2 原生 TCP shell + PTY 与 xterm 解析，不增加中转服务或自行解析 ANSI。

## 默认界面

- SSH 独占应用可用屏幕，无外层页面滚动；终端自己管理历史滚动。
- 简洁深色顶部显示目标名称、连接状态和地址摘要。点顶部可看完整目标和说明；键盘按钮显式打开/收起输入。
- 仅 SSH 路由存在时解除普通台账 760px 阅读宽度上限，横屏终端可使用完整宽度。退出后恢复普通页面宽度。
- 安全区和键盘遮挡由 Scaffold/MediaQuery 处理，PTY 跟随真实终端尺寸变化；连接前也先记录测量尺寸。布局完成后按实际光标矩形校正输入行可见性，不能只检查行数减少。被动键盘/旋转变化保留正在阅读的历史锚点；显式点键盘或回到最新输出才回到输入位置。
- 短横屏键盘开启时收紧顶部与边距；不足以保留一行终端的极短视口暂收底栏，顶部保留命令入口。文字缩放不靠压小终端字体来规避。
- 底部单行横滑快捷键保持在键盘上方：Ctrl（一次性）、Esc、Tab、Ctrl+C、Ctrl V、方向键、Enter、Home、End。直接终端特殊键不夺走键盘焦点；Ctrl V 有意打开本地草稿。Ctrl 再点可取消，离开输入/断线时清除。
- 软键盘启用 xterm 的删除检测；直接输入、中文候选上屏、退格与特殊键按终端协议写入。底栏 Enter 提供明确的回车入口。手机不同 IME 的 `newline`/`done` 事件方式仍须实机检查，组件测试不替代设备验证。
- 长按/拖动选择输出后出现复制入口；复制不发 SSH 字节。上滚查看历史时提供回到最新输出的入口。
- 断线保留输出供查看，重连显式清空本次终端和草稿，不重放旧输入。活动会话返回/断开有确认，取消保持原会话。后台清理规则不变。

## 命令、片段与粘贴

“命令”抽屉集中放置常用命令和原有用户片段，只有一个本地草稿。常用项 `pwd`、`ls -lah`、`uptime`、`df -h`、`free -h` 无修改性操作；它们只是 Linux 常见示例，不保证每个远端都安装。点选只填入草稿，不自动发送或执行；替换未发送草稿需确认。

面板按“常用命令 → 插入片段 → 可编辑草稿与粘贴 → 完整目标与条件性提示 → 回车说明 → 发送动作”排列；命令选择与文本编辑用分隔线区分，粘贴不再与片段选择混成一行。正文保持单一纵向滚动，短屏/键盘占位下仍可滚到两种发送动作。

用户片段仍通过现有列表增改查删和完整转义预览选择。发送区保留就地编辑，显示完整目标；含 CR/LF/控制字符/bidi 时就地显示转义原文及风险提示。不再弹出额外的发送预览，也没有追加回车勾选：

- “发送”：发送草稿原文，空格、中文和现有 CR/LF 均不更改，不额外追加回车。
- “发送并执行”：发送同一原文，再追加且只追加一个 CR。
- 原文已有 CR/LF 或控制字符仍可能立即执行；不追加回车不等于绝不执行，也不通过 bracketed-paste 包装暗中改变字节。按钮只表达本地发送意图，不能确认远端执行成功。
- 草稿为空、连接不可写或会话过期时禁用两个按钮；重复点击只写一次。失败保留草稿并提示核实远端结果，无自动重试。取消、切换目标、断线、重连不会自动发送或重放。

快捷栏“Ctrl V”、草稿区/菜单粘贴和硬件 Ctrl+V/Cmd+V 路由到同一可编辑草稿；它们是本地粘贴动作，不发送 0x16。只在用户触发时读取系统剪贴板，按当前选区插入，不保存或记录剪贴板内容。异步读取期间切换目标、关闭抽屉、离开页面或修改草稿会丢弃迟到结果，重复点击不会并发读取。直接键盘输入（包括键盘自身提供的剪贴板输入）属于即时终端输入，用户应使用这些草稿粘贴入口来获得复核。硬件 Ctrl+A 保留 shell 行首语义，Ctrl+Shift+C/Cmd+C 复制选择。

连接、目标和异步操作继续使用 generation/epoch 校验；重建终端输入控件清除上一会话未提交的 IME 组合状态。首次/变化主机公钥确认、临时私钥口令与单机电源二次确认沿用原安全流程。没有改变私钥存储、保存新口令或自动运行远端命令。

## 离线开源字体

默认单一 DejaVu Sans Mono 2.37，常规 + 真粗体合计 677,408 字节（压缩前）；来源、SHA-256 和完整许可见 `assets/fonts/README.md` / `LICENSE-DejaVu.txt`，App 的会话详情可打开许可列表。无运行时字体下载。

14px / 1.3 行高，ASCII 和框线采用一致的单格宽度；禁用编码连字与 kerning，避免 `!=`、`->` 等被替换成不同外观。中文采用系统 Noto CJK / PingFang 回退并由 xterm 保留双格宽度。真实设备中文 fallback、emoji、所有脚本和各种 IME 仍需验收，不因字体文件存在就宣称全平台一致。

## 验证入口

- `test/terminal_widget_test.dart`：既有安全、草稿/片段、host-key、私钥口令、电源和连接生命周期回归。
- `test/terminal_fullscreen_review_test.dart`：独立全屏、320/390/844px、1×/2×、键盘 inset、IME、控件保焦点、会话重置和本地 fixture 交互。
- `test/terminal_keyboard_send_review_test.dart`：独立真实字体光标边界、历史与旋转、双按钮、剪贴板延迟/选区/关闭/重连、混合重复点击和发送后 IME 连续输入。
- `test/terminal_keyboard_send_loopback_review_test.dart`：两个按钮和剪贴板草稿通过真实 loopback SSH/PTY，以 UTF-8 字节核对原文和末尾单个 CR。
- `test/terminal_linux_engine_test.dart`：Linux engine 的历史锚点、alternate-screen 合成 TUI、反复键盘 inset、不可写/异常恢复与短横屏大字。设置 `VPS_SSH_LINUX_QA_EVIDENCE` 可输出截图与测量；截图需提供真实 CJK 字体，普通回归不依赖宿主字体路径。
- `test/terminal_font_test.dart`：离线字节/许可固定、渲染特性、真实常规/粗体固定格宽与中文终端格数。
- `test/ssh_service_test.dart`：仅 loopback、独立 AsyncSSH、不执行 shell/exec 的真实协议 fixture，覆盖认证、PTY、resize、UTF-8 和断线。

本轮最终通过数量、截图、review 和构建证据以后续 STATUS/ACCEPTANCE 完成记录为准。本轮 Linux Flutter engine 和合成 viewInsets 验证不等于 GTK 原生键盘/系统剪贴板验证；隔离显示服务受本地 socket 限制未能启动。Android/iOS 真机、真实 VPS 兼容性及新 APK 不属于这里的已验证结论。
