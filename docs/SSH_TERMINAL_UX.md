# 全屏 SSH 与移动输入

本轮键盘与发送体验改进基于已发布 `9eb94af2e8697c94cae4d5e0ae8afa0590651771`；不改变凭据、主机信任、SQLite schema 或远端授权。SSH 继续通过 dartssh2 原生 TCP shell + PTY 与 xterm 解析，不增加中转服务或自行解析 ANSI。

## 默认界面

- SSH 独占应用可用屏幕，无外层页面滚动；终端自己管理历史滚动。
- 简洁深色顶部显示目标名称、连接状态和地址摘要。点顶部可看完整目标和说明；键盘按钮显式打开/收起输入。
- 仅 SSH 路由存在时解除普通台账 760px 阅读宽度上限，横屏终端可使用完整宽度。退出后恢复普通页面宽度。
- 安全区和键盘遮挡由 Scaffold/MediaQuery 处理，PTY 跟随真实终端尺寸变化；连接前也先记录测量尺寸。布局完成后按实际光标矩形校正输入行可见性，不能只检查行数减少。被动键盘/旋转变化保留正在阅读的历史锚点；显式点键盘或回到最新输出才回到输入位置。
- 短横屏键盘开启时收紧顶部与边距；不足以保留一行终端的极短视口暂收底栏，顶部保留命令入口。文字缩放不靠压小终端字体来规避。
- 底部单行横滑快捷键保持在键盘上方：Ctrl（一次性）、Esc、Tab、Ctrl+C、Ctrl V、方向键、Enter、Home、End。直接终端特殊键不夺走键盘焦点；Ctrl V 有意打开本地草稿。Ctrl 再点可取消，离开输入/断线时清除。
- 软键盘启用 xterm 的删除检测；直接输入、中文候选上屏、退格与特殊键按终端协议写入。底栏 Enter 提供明确的回车入口。手机不同 IME 的 `newline`/`done` 事件方式仍须实机检查，组件测试不替代设备验证。
- 长按/拖动选择输出后出现复制入口；复制不发 SSH 字节。上滚查看历史时提供回到最新输出的入口。
- 会话结束即关闭页面：远端关闭、网络中断、取消连接、在后台停留过久（见下文“后台”）或点关闭，终端页都会自动返回上一页，并丢弃未发送草稿（无确认、无“离线”状态，也没有重连入口）。已建立的会话结束时，上一页用提示条说明（“已断开”、后台/目标变化原因或服务端错误）。再次连接总是打开新页面，不重放旧输入、不自动重连。
- 会话建立前的失败（认证失败、主机公钥被拒或不再可信、超时）同样关闭终端页，但错误随返回值显示在连接页顶部的红色横幅里，便于修改后重试；用户自己取消连接则不提示。
- 点关闭/系统返回：连接中直接取消；已连接时只确认一次（断开会结束远端 shell，未发送草稿将丢弃），取消保持原会话。

## 后台

离开应用不再立即断开 SSH：先向系统申请一小段后台时间，用完才干净关闭。实现在 `lib/core/background_grace.dart`，终端页和独立 SFTP 页各自注册为会话。

- **iOS**：应用进入 `hidden/paused` 时，若有已连接的会话，调用一次 `UIApplication.beginBackgroundTask(withName:expirationHandler:)`（`ios/Runner/BackgroundTimeChannel.swift`，通道 `vps_tell_you/background`：`begin / end / remaining`，原生到 Dart 的 `expiring`）。多个会话共用这一个任务。这是普通后台任务接口，**没有**声明任何后台模式（不用音频、VoIP、定位），App Review 无需额外说明。
- **时间由系统决定，不是承诺值**：iOS 13 起通常约 30 秒（旧的 iOS 7–12 约 180 秒已不适用）。iOS 26.2 模拟器实测：进入后台后 `backgroundTimeRemaining` 约 30 秒并逐秒递减；`begin` 调用瞬间读到的是“前台”的极大值（`Double.greatestFiniteMagnitude`），约 0.2 秒后才是真实值，所以 Dart 会重读。模拟器与真机、不同系统版本、低电量模式下可能不同；真机未测。
- **关闭时机**：Dart 在剩余时间前约 3 秒主动断开所有会话（并交还任务）；若系统先触发过期回调，原生发 `expiring`，Dart 同步断开后原生立刻结束任务（Dart 不应答时 0.5 秒后兜底结束）。模拟器实测：后台约 26 秒时关闭，原生过期回调约在 26 秒时到达。
- **回到前台**：在到期前回来，结束任务，会话和终端原样继续，不重连、不重放输入。若进程被冻结而计时器没触发，回来时按单调时钟判断已超时，同样关闭。
- **关闭后**：终端页返回上一页并显示“应用在后台停留过久，与 user@host:端口 的 SSH 会话已结束”；SFTP 页返回并显示对应 SFTP 文案，运行中的传输被取消并清理残留文件。后台期间草稿不会被发送；终端不会自行重连，也不会重放任何输入。尚在连接/口令输入中的终端在进入后台时直接取消（与之前相同）。
- **Android 与其他平台**：没有可度量的额度，也没有前台服务（前台服务需要常驻通知和商店声明，不符合“空闲 shell”的用途），因此固定保留 30 秒（`fixedBackgroundGrace`）后同样关闭。这是尽力而为：进程一旦被系统冻结或回收，TCP 连接无法保证存活。
- **SFTP 传输**：运行中的上传 / 下载在宽限期内继续，到期取消。没有使用 iOS 26 的 `BGContinuedProcessingTask`：它只在 iOS 26+ 可用（用户手机是 iOS 18.7），需要带通配符的任务标识与系统进度界面，且本轮无法在真机验证；也不会用它保活空闲 shell。后续若要“后台继续传大文件”，应单独做并真机验证。
- **未做本地通知**：关闭发生时应用已在后台，发通知需要通知权限与现有提醒通道的新类别，收益有限；改为回到应用时显示上述提示。
- 选择文件 / 分享面板（Android 上会让应用进入后台）打开时，SFTP 页不会因此被关闭。

## 配色与智能高亮

终端 ⋯ 菜单的“配色与高亮”提供 4 套配色（Tokyo Night 默认、Catppuccin Mocha、Dracula、GitHub Light）和“智能高亮”开关（默认开），仅本次运行有效。配色只换调色板；高亮是纯客户端的显示效果：

- 只给**默认前景色**的单元格上色，远端 ANSI 颜色（含背景、反色、256/真彩色）原样保留，并作为分词边界。
- 不改变收发字节或文字内容；选择/复制只读字符码点，不受影响。颜色以 ANSI 调色板槽位写入单元格前景（附一个 xterm 调色板忽略的标记位），所以换配色会立即重新着色，关闭时可精确撤销，远端覆盖该单元格后自然失效。
- 识别：提示符（user@host、路径、`#`/`$`）、IPv4/IPv6/MAC、URL、绝对/相对路径、带单位的数字（K/M/G、%、ms…）、日期时间、引号字符串、UUID/十六进制、`key=value` 的键、error/fail/denied（红）、warn（黄）、ok/active/running（绿）、HTTP 状态码、`ls -l` 行的文件名（目录/可执行/链接）、整行 `#`/`//` 注释。
- 性能：只处理视口附近的行，且仅当该行内容变化；每次处理有时间预算并节流（约 25 次/秒）；每行最多检查 400 个单元格。备用屏幕（vim/top/htop）不处理。

SFTP 文本编辑器按文件名/扩展名/shebang 做语法高亮（Shell、YAML、JSON、INI/conf、nginx、Dockerfile、Python、JS/TS、Markdown、XML/HTML、SQL，其余为通用），配色取自同一终端配色，并按应用深浅色选择；超过 256 KiB 不高亮。⋯ 菜单可切换语言或关闭。

## 命令、片段与粘贴

“命令”抽屉集中放置常用命令和原有用户片段，只有一个本地草稿。常用项 `pwd`、`ls -lah`、`uptime`、`df -h`、`free -h` 无修改性操作；它们只是 Linux 常见示例，不保证每个远端都安装。点选只填入草稿，不自动发送或执行；替换未发送草稿需确认。

面板按“常用命令 → 插入片段 → 可编辑草稿与粘贴 → 完整目标与条件性提示 → 回车说明 → 发送动作”排列；命令选择与文本编辑用分隔线区分，粘贴不再与片段选择混成一行。正文保持单一纵向滚动，短屏/键盘占位下仍可滚到两种发送动作。

用户片段仍通过现有列表增改查删和完整转义预览选择。发送区保留就地编辑，显示完整目标；含 CR/LF/控制字符/bidi 时就地显示转义原文及风险提示。不再弹出额外的发送预览，也没有追加回车勾选：

- “发送”：发送草稿原文，空格、中文和现有 CR/LF 均不更改，不额外追加回车。
- “发送并执行”：发送同一原文，再追加且只追加一个 CR。
- 原文已有 CR/LF 或控制字符仍可能立即执行；不追加回车不等于绝不执行，也不通过 bracketed-paste 包装暗中改变字节。按钮只表达本地发送意图，不能确认远端执行成功。
- 草稿为空、连接不可写或会话过期时禁用两个按钮；重复点击只写一次。失败保留草稿并提示核实远端结果，无自动重试。取消、切换目标、断线不会自动发送或重放；会话结束时页面（连同命令面板）随之关闭，草稿被丢弃。

快捷栏“Ctrl V”、草稿区/菜单粘贴和硬件 Ctrl+V/Cmd+V 路由到同一可编辑草稿；它们是本地粘贴动作，不发送 0x16。只在用户触发时读取系统剪贴板，按当前选区插入，不保存或记录剪贴板内容。异步读取期间切换目标、关闭抽屉、离开页面或修改草稿会丢弃迟到结果，重复点击不会并发读取。直接键盘输入（包括键盘自身提供的剪贴板输入）属于即时终端输入，用户应使用这些草稿粘贴入口来获得复核。硬件 Ctrl+A 保留 shell 行首语义，Ctrl+Shift+C/Cmd+C 复制选择。

连接、目标和异步操作继续使用 generation/epoch 校验；页面随会话关闭，上一会话未提交的 IME 组合状态随终端输入控件一并销毁。首次/变化主机公钥确认、临时私钥口令与单机电源二次确认沿用原安全流程。没有改变私钥存储、保存新口令或自动运行远端命令。

## SFTP 文件管理

两个入口，同一个浏览器（`lib/connections/sftp_pages.dart`）：

- **服务器详情 → 连接与控制 → “SFTP 文件”**（`server-sftp`，紧随 SSH 连接）：可用性与 SSH 相同——已归档 / 演示记录置灰并提示原因，未配置 SSH 时置灰并引导去配置；凭据缺失时提示去 SSH 设置。点击后进入“正在连接 SFTP…”页（可取消），走与终端**同一条**连接路径（`NativeSshService.connectSftp`）：同一套主机公钥首次 / 变化核验弹窗和加密私钥口令弹窗（`ssh_prompts.dart`，由终端页抽出共用，未复制安全逻辑）。核验前不发送任何认证字节。成功后页面替换为浏览器并拥有该连接：关闭页面即关闭连接；应用进入后台时与终端一致：先保留一小段宽限时间，超时才关闭并提示（见“后台”）。失败在本页简短显示，可重试。
- **终端 ⋯ 菜单 → “SFTP 文件”**：在**同一条已连接的 SSH 会话**上另开 SFTP 通道（`openSftpOnClient`），以大页面板（page sheet）显示。不重连、不重新认证、不向 shell 写任何字节，命令草稿保留。关闭面板只关闭 SFTP 通道；SSH 会话结束时终端页关闭，面板随之关闭。

### 行为

- 起始目录为服务器 home。标题为当前文件夹名，下方路径面包屑可点各级、横向滚动；“上级目录”行返回上层。文件夹优先，可按名称 / 大小 / 修改时间排序，隐藏文件默认不显示，搜索框过滤当前目录。超过 200 项分页显示。下拉刷新。
- 每行显示图标（文件夹 / 文件 / 链接）、名称（最多三行）、大小与修改时间，以及权限串作为次要行。点文件夹进入；点文件弹出操作：查看/编辑（文本且 ≤ 512 KiB）、下载、重命名/移动、复制路径、删除。长按同样；左滑显示重命名与删除。
- 新建文件夹、新建空文件（已存在则报错，不覆盖）、重命名/移动（名称加文件夹路径；目标已存在则报错，不覆盖）。
- 删除：先确认；文件与链接直接删除（链接只删链接，不跟随）。文件夹先尝试删除空目录，非空则**第二次明确确认**“递归删除”，并说明条目上限（2000）；超限则整体拒绝、不删任何内容。
- 编辑器：UTF-8 等宽编辑，保存前比较服务器上文件的大小与修改时间，已变化则询问是否覆盖；有未保存修改时关闭会询问。保存经临时文件 + 重命名，失败不会留下写了一半的目标，并尽量保留原文件权限位。二进制或非 UTF-8 文件提示“不是 UTF-8 文本文件”，不打开。
- 传输：底部进度条（点开为完整列表），串行队列，每项可取消；上传选择系统文件选择器（`file_selector`，iOS 为“文件”选取器），重名时询问覆盖 / 跳过；下载保存到应用文档目录下 `SFTP Downloads/`（重名自动编号，不覆盖），完成后提示保存位置并提供“分享”（系统分享面板，iOS 可“存储到文件”）。超过 100 MB 的上传 / 下载先确认。取消或失败会清理本地 / 远端的临时半成品。传输进行中关闭页面会先询问。
- 错误统一为简短本地化提示：没有权限、未找到、已存在、文件夹不为空、文件过大、不是文本、超时、连接已断开、本地文件读写失败等；连接断开后页面显示“SFTP 连接已断开”并只允许关闭。服务器原文不显示、不记录。

### 限制与安全边界

- 不记录文件内容、路径之外的服务器原文或秘密；不做端口转发、不执行远端命令（SFTP 子系统只处理文件）。
- 路径不在客户端做“防穿越”判断，访问范围完全由服务器账户权限 / chroot 决定；客户端只做空路径、NUL 与长度检查，递归删除额外拒绝 `/`、`.`、`..`。
- 重命名的“目标不存在”检查与实际重命名之间有极小竞态（OpenSSH 的 posix-rename 会替换目标）；上传的临时文件名为 `.<名称>.<随机>.part`，连接中断时可能残留在服务器。
- 部分服务器禁用 SFTP：dartssh2 不报告子系统被拒，表现为握手无响应，约 15 秒后提示“此连接无法使用 SFTP”。
- Android 的文件选择器会把所选文件整个读入内存（file_selector_android 的限制），选择超大文件有内存风险。
- 下载位置：iOS 为应用 Documents 下的 `SFTP Downloads/`，`Info.plist` 已开启 `UIFileSharingEnabled` 与 `LSSupportsOpeningDocumentsInPlace`，因此在“文件”App 的“我的 iPhone / 本应用”中可见（Documents 只存放用户导出，账本数据库在不可见的 Application Support）；Android 为应用私有文档目录，需通过“分享”另存；桌面为系统“下载”目录。
- 验证：`test/sftp_session_test.dart`（会话层 loopback）、`test/sftp_ui_test.dart`（浏览器 / 编辑器 / 传输 / 320px×2 倍字号）、`test/sftp_entry_test.dart`（详情入口、连接页、终端面板且 shell 零字节）、`test/sftp_loopback_ui_test.dart`（浏览器对真实 loopback SFTP）。真机的文件选择器、分享面板与“文件”App 可见性仍须设备验证。

## 代理（SOCKS5 / HTTP / HTTPS）

SSH（终端与 SFTP）和 TCP 检测可以经代理服务器连接；留空即直连。代理只作用于**你主动发起**的这三类连接，不是系统代理，应用的其他网络请求（提供商目录下载）不受影响。

- **保存的代理**：设置 → 密钥与安全 → “代理”。名称、类型（SOCKS5 / HTTP / HTTPS，默认端口 1080 / 8080 / 443）、主机、端口、可选用户名与密码。元数据在 SQLite 表 `proxies`（schema v14），**密码只在设备安全存储**（引用 `vps_proxy_…`，与凭据相同的“先预留、写入、校验、提交；被替换/删除的引用进入 `secret_cleanup` 重试清理”流程）；不进入 JSON 备份。编辑时密码留空表示保留；清空用户名同时删除密码。查看已保存密码需要设备验证（与凭据相同，20 秒后隐藏）。
- **SSH 连接配置**的“代理”行：直连 / 已保存代理 / “新建代理…”。服务器详情的 SSH 行副标题显示“经 <代理名>”。`ssh_configurations.proxy_id` 外键为 `ON DELETE RESTRICT`：**仍被引用的代理不能删除**（界面禁用并说明有几台服务器在用），不会让连接悄悄变成直连。连接时代理缺失、密码缺失或被改动一律**失败**，不回退直连。
- **TCP 检测页**的“代理”行：直连（默认）/ 已保存代理 / “输入代理…”（临时：只用于本次，不保存，密码不写入任何存储）。结果显示路径（直连 / 经代理）；经代理时“实际地址”是**代理的**地址，成功只证明代理能到达目标，不证明本机能直接到达。
- **传输**（`lib/connections/proxy_connector.dart`，纯 `dart:io`）：
  - SOCKS5（RFC 1928）：无认证或用户名/密码（RFC 1929）；CONNECT 的目标地址类型按输入选择 IPv4 / IPv6 / **域名**——域名原样发给代理，由代理解析（远程 DNS），本机不解析目标。应答码 1–8 分别对应本地化错误。
  - HTTP：`CONNECT host:port`，IPv6 字面量加方括号；配置了用户名时发送 `Proxy-Authorization: Basic`；响应头（含状态行）最大 16 KiB，2xx 成功，407 区分“需要凭据 / 凭据被拒”，其他状态显示状态码；头之后的字节原样交给隧道。
  - HTTPS 代理：先与代理做 TLS（**正常证书校验，没有“忽略证书”选项**；主机名按代理主机核对），再发 CONNECT。
  - 取消与超时与直连一致：一个对象持有连接任务和迟到的 socket，取消后迟到的 socket 被销毁；SSH 阶段计时器到期时提示“通过代理连接超时”。用户名/密码字节数 1–255，HTTP 用户名不能含冒号。区域 ID（`%en0`）的链路本地地址不能经代理。
- **主机公钥信任仍以目标 `主机:端口` 为键**，与是否使用代理无关；日志和错误不含代理主机、用户名或密码。
- 验证：`test/proxy_connector_test.dart`（回环假代理：SOCKS5 有/无认证、错误密码、全部应答码、域名/IPv6、早到数据、分片应答；HTTP 200/407/502、分片头、超大头、IPv6 括号；HTTPS 测试 CA / 他人 CA / 系统信任库，`test/fixtures/proxy_tls/`）、`test/proxy_ssh_e2e_test.dart`（对 AsyncSSH 回环夹具：SSH 经四种代理、SFTP 经 SOCKS5、终端上的 SFTP、失败不回退直连、TCP 检测经代理）、`test/proxy_store_test.dart`、`test/schema14_store_migration_test.dart`、`test/proxy_widget_test.dart`。真实代理软件与 iOS 上的 HTTPS 证书链（Apple 对服务器证书有效期的限制）仍需设备验证。

## 离线开源字体

默认单一 DejaVu Sans Mono 2.37，常规 + 真粗体合计 677,408 字节（压缩前）；来源、SHA-256 和完整许可见 `assets/fonts/README.md` / `LICENSE-DejaVu.txt`，App 的会话详情可打开许可列表。无运行时字体下载。

14px / 1.3 行高，ASCII 和框线采用一致的单格宽度；禁用编码连字与 kerning，避免 `!=`、`->` 等被替换成不同外观。中文采用系统 Noto CJK / PingFang 回退并由 xterm 保留双格宽度。真实设备中文 fallback、emoji、所有脚本和各种 IME 仍需验收，不因字体文件存在就宣称全平台一致。
