VPS Tell You移动端 UI 重设计 · 交互 Demo v1

设计原则

  1. 一套界面，两端一致：以 iOS 为基准，Android 使用完全相同的组件和交互，只保留系统字体、状态栏和系统返回键 / 手势。
  2. 列表优先，少用描边：去掉白卡外 1px 描边和描边按钮，用分组列表、浅色填充、层级字重来区分层次。
  3. 先给结论，说明后置：说明文字放到分组底部的小字或 ⓘ 弹层里；状态用色彩胶囊表示，不再整段说明。
  4. 手势与就地操作：下拉刷新、左滑常用/归档、长按快捷菜单、底部弹层筛选，少用页面中间的对话框。
  5. 安全边界不变：归档、电源、凭据、主机指纹等确认流程一个不少，只换成更符合平台习惯的呈现方式。
