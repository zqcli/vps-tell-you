## 前一增量：真机反馈第四轮（分支 `feat/mobile-ui-redesign`）

- **付款删除回退**：原来能否回退取决于服务器的 revision，收藏、改名这类无关编辑也会让回退失效，导致删除付款后到期日停在 2028、无法重新续费 2027。现在改为看服务期状态：只要这笔付款是末尾的那组续费、周期没变，就允许回退。界面提交时带上当前的 revision，在事务内重新校验。对末尾的续费，删除菜单默认「删除并回退到期日」；不是末尾的，只能删除记录，并说明需要先删除后面的续费。已经处于「付款已删除但服务期还在」状态的数据，详情页和付款列表会显示琥珀色横幅，确认后用 `rollbackOrphanTerm` 修复。
- **终端智能高亮**：客户端按语义上色，包括提示符、IP、URL、路径、数字和单位、日期、错误 / 警告 / 成功关键字、HTTP 状态码、`ls -l` 文件类型等。只给默认颜色的单元格上色，远端发来的 ANSI 颜色保持不变；不改动文本，也不收发任何额外字节；vim、top 这类全屏程序不处理；只处理视口附近的行，有时间预算。可在终端 ⋯「配色与高亮」中开关。
- **SFTP 编辑器语法高亮**：内置轻量高亮器，支持 shell、YAML、JSON、INI / conf / env / systemd、nginx、Dockerfile、Python、JS / TS、Markdown、XML / HTML、SQL。颜色和终端配色一致，编辑时只重新分析改动的行；超过 256 KiB 的文件不高亮。
