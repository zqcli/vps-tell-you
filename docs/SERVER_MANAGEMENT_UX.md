# 服务器资料与云关联整理

日期：2026-10-06 UTC。基线：已发布 `943a916ac823ead6c7a2259a5cc355b896dab6ae`。

## 交互与数据决定

- 手动新增和编辑复用同一份六项硬件表单：IP、Hostname、磁盘、流量、内存和 vCPU。不知道可留空；空值不等于 0 或不限量。SolusVM 1 导入仍要求核对并补齐六项。
- 硬件信息创建后仅手动维护。云账户刷新、关联、更换关联及解除关联都不覆盖本地硬件、费用或 SSH。详情始终显示硬件区，旧记录可以补填。
- 流量容量按整数字节保存，周期另存为月、季、年或未设置，与计费周期无关。新手动记录明确默认月；旧记录及 API 导入不推断周期。
- 新建时主机地址留空，可采用硬件 IP 或 Hostname。已存在服务器的主机地址保持独立，修改硬件不会暗改连接目标；SSH 配置仍独立维护。
- 详情取消多字段 API 观测卡，保留简洁云厂商关联入口。后台观测仍用于导入、去重、实例身份及关联安全校验。
- 服务器侧可选已保存的云账户及未占用实例，或确认更换/解除当前关联。该页面只读本地保存的列表，不自动连接厂商；失效/缺失观测需用户到云账户手动刷新。占用实例不会被抢绑。
- 费用、续费列表、付款记录页移除独立账户账单新增入口。服务器续费、费用统计、已有付款及历史独立账单保留，不删除用户账务。

## 一致性与兼容

SQLite schema v8 为资源 JSON 格式提供旧客户端版本围栏。v7 → v8 不重写任何行，不虚构硬件、流量周期或付款。旧八字段资源 JSON 保持完整校验；新九字段允许未知硬件及独立流量周期。台账备份 v1 可恢复旧完整资源及新部分硬件；未知/私人扩展键仍拒绝。

服务器关联选择从同一 SQLite 事务取得快照。保存事务检查服务器版本、云账户版本/generation、原关联与实例占用；关联变更推进全部已有账户 generation，阻挡跨账户解绑/重绑 ABA。不变更服务器 revision，保留既有安全付款撤销能力。取消/冲突回滚，成功后重读失败明确显示已保存并禁止重复提交。

## 验证范围

所有新增测试只使用合成台账、内存秘密存储及 mock 适配器；关联流程断言不读取、写入或删除秘密且不创建远端请求。不使用真实 API 凭据，不执行远端电源或配置写入，不改变 RackNerd 协议兼容。

自动测试覆盖：手动留空/全部填写/非法值、单位与周期独立、旧 JSON/数据库/备份、保存后重开、表单滚动与取消、重复保存、关联占用/过期页面/跨账户 ABA、确认取消、事务取消、提交后读取失败、付款撤销与历史账单保留。手机宽度 390px、2 倍文字下进行组件交互回归。

原生独立显示测试尝试启动专用 Xorg display，但执行环境无法建立本地显示 socket。未操作既有用户窗口或钥匙环；原生 GUI 和手机真机测试未因此宣称通过。最终 aggregate、独立 review 和 release build 结果见 STATUS/ACCEPTANCE。
