# 服务器资料与云关联整理

日期：2026-10-06 UTC。基线：已发布 `943a916ac823ead6c7a2259a5cc355b896dab6ae`。

## 交互与数据决定

- 手动新增和编辑复用同一份六项硬件表单：IP、Hostname、磁盘、流量、内存和 vCPU。不知道可留空；空值不等于 0 或不限量。SolusVM 1 导入仍要求核对并补齐六项。
- 硬件信息创建后仅手动维护。云账户刷新、关联、更换关联及解除关联都不覆盖本地硬件、费用或 SSH。详情始终显示硬件区，旧记录可以补填。
- 流量容量按整数字节保存，周期另存为月、季、年或未设置，与计费周期无关。新手动记录明确默认月；旧记录及 API 导入不推断周期。
- 新建时主机地址留空，可采用硬件 IP 或 Hostname。已存在服务器的主机地址保持独立，修改硬件不会暗改连接目标；SSH 配置仍独立维护。
- 详情取消多字段 API 观测卡，保留简洁云厂商关联入口。后台观测仍用于导入、去重、实例身份及关联安全校验。
- 服务器侧可选已保存的云账户及未占用实例，或确认更换/解除当前关联。该页面只读本地保存的列表，不自动连接厂商；失效/缺失观测需用户到云账户手动刷新。占用实例不会被抢绑。
- 费用、续费列表、付款记录页移除独立账户账单新增入口。服务器续费、费用统计、已有付款及历史独立账单保留，不删除用户账务。

## 紧凑容量输入（2026-10-06）

基于已发布 `17e41171ea473e43c6126f1e640c0bdb7129c4bd`，共享硬件表单将磁盘和内存改为“容量 + 单位”同行，将流量改为“容量 + 单位 + 周期”同行。手动新增、编辑与面板补填复用同一组件。

完整字段名、1024 进制说明、来源和校验错误放在输入行外，避免挤压窄屏控件。单位为其完整文字预留宽度；月、季、年和“未设置”均保留。最窄屏幕放大文字时，“未设置”可以在同一控件内换行。长容量数字保持标准文本框的光标与横向编辑滚动，不四舍五入或截断保存值。

这是纯表单布局调整：schema 仍为 v8，无数据库迁移；未知值、明确不限量、新建默认月、旧资料周期未设置、精确单位计算、原校验与来源/持久化规则均保持。不限量只禁用容量和单位，仍可修改流量周期。

## 从“可填写”到更顺手（2026-10-06）

本轮按新增、编辑、导入和错误恢复的完整路径审查，不把“测试能过”视作实际使用体验已经完成。

- 新建首屏说明名称/厂商必填，硬件和费用可后补；基本资料、硬件、费用边界明确。“规格”改为“规格补充”，提示 CPU 型号/网络带宽，避免与结构化容量字段混淆。
- 计费方式、原币种和付款周期采用标签与选择器同排；选中项用短而明确的文字，打开菜单仍保留完整含义。金额旁显示当前币种及每周期含义，切换币种/周期不改写输入金额或历史实付。
- 不限流量是短标签与开关同排，整行可点；未知/0 不会自动开启。通用容量规则移到组级，实际 API/手动来源保留，空白手动字段不重复展示同一句未知说明。
- 容量周期只由当前选中项决定高度，放大文字下不再为未选中的“未设置”留下高空框；文字大时仍允许合理换行，不裁剪单位或值。
- 保存时同时核对基本/费用与硬件，把最早的可修字段滚入视口，保留全部草稿；日期先后错误直接标在到期日。字段错误完整换行，读屏继续得到错误标签/invalid 状态。
- SolusVM 1 未勾选时明确显示原因，并从提交区提供“返回选择实例”；返回只定位，不代勾选、不提交、不新增读取。缺资源时定位到对应错误字段。
- 地址关闭自动纠错，单行字段提供下一项动作、日期使用日期键盘、备注保留多行换行；这些仅完成组件/源码验证，手机输入法表现仍需设备验证。
- 日期说明改为自然语言，备注明确指向现有“密钥与安全”，移除过时的“后续提供”说明。

仍建议另行确定：长表单误返回的草稿保护、日期选择器与手输并存、详情的就近分区编辑，以及可选字段的渐进展开。这些会改变退出或导航行为，本轮没有擅自加入。

## 费用与日期按组同行（2026-10-06）

依照最新明确布局，计费方式继续使用选择器，但恢复与 vCPU 输入一致的框上浮动标签。预付费的金额、币种与付款周期放在同一行；开始日期与结束日期放在同一行。按量仍是月估算，不引入可编辑的预付周期或日期；费用未知和免费规则不变。

周期闭合选项使用月、季、半年、年、2年、3年，菜单及读屏保留完整周期含义。金额下方保留完整原币金额与周期摘要，便于核对窄文本框中横向滚动的长数值，不执行币种换算或四舍五入。

日期可在同一文本框内随字号软换行，完整显示 YYYY-MM-DD；controller 与保存值不插入换行，仍按原严格日期规则校验。开始/结束日期错误在整行下方明确区分，输入保留完整“服务开始日/服务到期日（选填）”语义及 invalid/valid 状态，保存失败继续定位首个错误。

本次只改表单组合、装饰与对应回归，数据库 schema v8、控制器、保存、历史付款锁定和精确金额/日期语义未变。运行中的旧预览目录不覆盖；新预览从独立目录构建。

## 一致性与兼容

SQLite schema v8 为资源 JSON 格式提供旧客户端版本围栏。v7 → v8 不重写任何行，不虚构硬件、流量周期或付款。旧八字段资源 JSON 保持完整校验；新九字段允许未知硬件及独立流量周期。台账备份 v1 可恢复旧完整资源及新部分硬件；未知/私人扩展键仍拒绝。

服务器关联选择从同一 SQLite 事务取得快照。保存事务检查服务器版本、云账户版本/generation、原关联与实例占用；关联变更推进全部已有账户 generation，阻挡跨账户解绑/重绑 ABA。不变更服务器 revision，保留既有安全付款撤销能力。取消/冲突回滚，成功后重读失败明确显示已保存并禁止重复提交。

## 验证范围

所有新增测试只使用合成台账、内存秘密存储及 mock 适配器；关联流程断言不读取、写入或删除秘密且不创建远端请求。不使用真实 API 凭据，不执行远端电源或配置写入，不改变 RackNerd 协议兼容。

自动测试覆盖：手动留空/全部填写/非法值、单位与周期独立、旧 JSON/数据库/备份、保存后重开、表单滚动与取消、重复保存、关联占用/过期页面/跨账户 ABA、确认取消、事务取消、提交后读取失败、付款撤销与历史账单保留。手机宽度 390px、2 倍文字下进行组件交互回归。

原生独立显示测试尝试启动专用 Xorg display，但执行环境无法建立本地显示 socket。未操作既有用户窗口或钥匙环；原生 GUI 和手机真机测试未因此宣称通过。最终 aggregate、独立 review 和 release build 结果见 STATUS/ACCEPTANCE。
