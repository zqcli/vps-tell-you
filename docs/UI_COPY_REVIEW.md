# 中文界面文案审定

日期：2026-10-07 UTC。基线：`132cd8e5f3b95d2422ec01635cb453232de8f15e`。

本轮覆盖现有中文界面、就近解释、空态、错误、确认框及导出结果，不增加英文界面或语言设置，不改变持久化模型、网络授权、金额算法、续费规则或用户输入内容。

## 统一用语

| 用语 | 界面中的准确含义 |
| --- | --- |
| 服务器 / 本地记录 | 台账中的服务器资料；不等于远端资源的生命周期 |
| 归档本地记录 | 从未归档列表及当前费用统计隐藏，可恢复；历史付款保留，厂商服务及计费不变 |
| 未归档服务器 | 本地归档状态；不再用“活动服务器”暗示在线或运行状态 |
| 面板账户 | SolusVM 只读连接及其本地授权；与厂商销售账户、独立账户账单、SSH 登录凭据分开 |
| 面板关联 | 本地服务器与面板实例的对应关系；解除不销毁实例、不撤销远端 Token |
| API 返回信息 / 上次读取 | 面板上一次返回的资料；不代表实时状态，不覆盖用户维护的硬件信息 |
| 主机地址 / 主机名 | IP 或域名与硬件 Hostname 各自明确；协议 token 和实际主机名不翻改 |
| 续费金额 / 续费周期 | 当前一个服务周期的价格和时长，不等于本次实际支付 |
| 开始日期 / 到期日期 | 表单中服务日期；到期当天不计入服务期，未知不补成已知日期 |
| 月费用参考 | 未到期预付续费价摊月加按量估算，不是本月实付账单 |
| 剩余价值 | 按已知服务期剩余天数和当前续费价折算，不是退款承诺或成交价 |
| 当前 / 尚未开始 / 已结束的周期 | 根据估值日描述进度条展示的服务期，避免把未来或历史周期叫“本周期” |
| 发送 / 发送并执行 | 保留用户指定按钮名；前者发送原文，后者追加回车，由当前终端程序处理 |
| 已安排提醒 | 已向系统提交并核对的待处理提醒，不是已经送达 |

金额为 0、未知、不适用、缺汇率分别表达；USD、EUR 等金额不再统称“0 元”。转让报价的结果明确附币种，并使用“预计”而非最终成交承诺。

## 审查与修正清单

### 服务器与硬件

- 新建、编辑、详情统一到期日期/续费周期，明确字段选填、日期推算和费用为 0 的含义。
- 新建主机地址取值说明贴近字段；主机地址、硬件信息与 SSH 地址互不误导。
- 磁盘容量、流量额度、内存容量、vCPU 核数及主机名标签一致；二进制容量、流量不限量、独立流量周期、API 预填来源均保留准确解释。
- “移除”统一为真实行为“归档”，确认框明确当前统计、历史付款、恢复与远端计费的边界。
- 演示数据的归档指引改为实际入口；搜索范围与到期核对的“台”计数符合实现。

### 费用、付款和计算器

- 月费用、未来 30 天（今天及后 29 天）、本月剩余日期及后五个月、近 30 天实付均用日常语言解释。
- 续费预测明确假设持续续费，使用计划不改变预测；部分未知/缺汇率明确呈现。
- 金额未知与已到期未计入分别说明；付款页不再把折算合计标成“原币合计”。
- 付款新到期日说明与整周期验证一致，不承诺任意修改厂商日期或赠送期。
- 已有续费服务期的锁定说明不承诺撤销一笔就可解除全部锁定，并指出可撤销范围有限。
- 估值卡、复制文本、PNG 使用一致的未来/当前/已结束周期描述及结束日不计入规则。
- 转让报价仅试算已填费用，明确不执行交易、不保证可转让、不含其他费用。

### 面板账户与关联

- 统一面板术语；读取超时仅保留历史返回信息，不断言远端状态未变。
- 首次验证失败不叫“授权过期”；读取 API 凭据失败与保存失败各给出相应恢复入口。
- V1 按独立连接识别，不宣称有稳定实例 ID；已关联实例跳过重复导入，按钮描述“新实例”。
- 六项资料的补齐提示不指向当前流程中不存在的“仅保存账户”按钮。
- V1 重授权按钮明确“更新授权并解除旧关联”；账户移除明确本地影响及重新授权要求。
- “已验证的读取范围”不夸大 Token 的真实权限。

### 凭据、SSH、命令、TCP 与电源

- 删除过期“本阶段没有网络连接”说明，配置页明确只保存配置。
- 手工主机公钥核对仅描述与本地信任记录的比较，不伪称已联网检测或阻断真实认证。
- 终端中更新变更后的主机信任会继续认证，确认按钮明确说明。
- 密码、私钥和解密口令提示分别对应正确输入和恢复方式；保存解密口令不等于更改私钥加密口令。
- 终端入口明确按键直接发送；命令和粘贴仍进入独立草稿，控制字符风险保留。
- 保留“发送”“发送并执行”及原有字节语义；进入后台主动断开、手动重连、不重放输入的说明与实现一致。
- 发送或电源指令结果未知时不再断言“未发送”，避免诱导重复操作；关机后需厂商面板开机。
- 终端复制异常新增安全失败提示，选区保留可重试；成功回调不清除期间新选出的内容。
- TCP 连通与业务健康、SSH 登录的区别保持明确；本轮未访问真实 SSH 或厂商 API。

### 设置、提醒、备份及错误

- 设置去除阶段编号、视觉版本等开发说明，保留开发测试版本标识。
- 到期当天提醒不显示“0 天前”；规则保存、通知允许、系统安排、实际送达分开说明。
- 时间选择器主要操作使用中文并以 24 小时制呈现；后续统一应用语言将接管 Material 内置文本。
- 备份说明包含硬件信息、明文风险、排除项及仅向空台账恢复；备份时间转为设备时间并标注。
- 通用操作失败不再归因为分组重复；分组保存、主机地址复制、终端复制各用具体且不泄露内部错误的提示。

## 验证范围

新增 `ui_copy_review_test.dart`：估值周期日期边界、当天提醒、通用错误不泄漏，以及 19 个页面和未来估值卡在 320 逻辑像素、2 倍文字下的逐段布局检查。通过同一真实 Noto CJK 字体的截图抽样验证；字体子集经字宽和轮廓一致性校验，只用于测试，不改变生产字体。

独立审查另检查已有对话框、取消/重复提交、主机核验、授权更新及草稿发送回归。19 页滚动检查本身只证明这些页面的布局没有异常，不替代所有状态分支或移动端真机验收。

最终分析、完整测试、Linux 构建及独立审查结果见 `ACCEPTANCE.md`。没有改变已运行应用、用户草稿、用户数据或钥匙环；平台边界通过合成与 mock 验证，未宣称 Android/iOS 真机验证通过。

## 后续语言切换交接

本轮没有引入 locale 或语言持久化。下一阶段应翻译界面文案、验证错误、通知、设备验证理由、复制文本/PNG 与 Material 内置控件，并按英文长度重新验证窄屏。

- 译文不能充当状态标识：`ServerForm.select` 的锁定条件目前比较中文标签；本地冲突的兜底提示目前匹配中文错误文字。国际化时应使用字段 ID / 错误类型，继续验证历史付款锁定与冲突保护。
- 分组默认名、演示资料、用户创建的名称和笔记、命令片段正文、IP/Hostname、协议 token、JSON key、数据库枚举及 ID 不应随切换语言改写。
- 本轮统一的“发送”“发送并执行”是用户明确指定的中文按钮名；英文本应保持对应的原文发送/追加回车语义，不更改发送路径。
- 保持未知 / 0 / 不适用 / 缺汇率及当前 / 未来 / 已结束服务期的区别，不能只翻译成功页而遗漏错误、确认框和导出文本。
